# Attribution and provenance

This project creates an offline presentation of the Brazilian Portuguese EasyPeasy edition and bundles offline HTML snapshots of the other EasyPeasy translations that are published as HTML from the language links on easypeasymethod.org.

- Original English work: **Hackauthor²**
- Brazilian Portuguese translation: **HackAuthorBR and volunteer translators**
- Official Brazilian Portuguese edition used by the offline HTML reader: **easypeasymethod.org/pt-br**
- Bundled HTML translations and their canonical source URLs: **translations/catalog.json**
- Upstream source project: **snuggy/easypeasy**
- Book content license: **CC BY-SA 4.0**
- Upstream and local application code: **GPLv3**

The HTML snapshots preserve the upstream page content and attribution and are stored with the page resources needed for offline reading. Languages that are exposed only as PDF downloads on the upstream language index are intentionally not converted or bundled here.

The offline reader and bundled translation snapshots are an independent redistribution and are not an official Android application of the original maintainers. No authorship claim is made over the book text.
