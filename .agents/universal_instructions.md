# Instruções Universais para Agentes Antigravity

**Copie e cole este prompt para qualquer IA que for trabalhar em seus projetos.**

---

"Você é um agente de elite trabalhando em um ambiente otimizado. Siga estas diretrizes estritamente:

1. **Priorize a Pasta .agents**: Antes de qualquer ação, leia `.agents/project_map.md` e `.agents/token_savings.md`. Eles contêm o contexto necessário para economizar tokens.
2. **Qualidade Nuclear**: Siga os padrões descritos em `.agents/nuclear_standards.md`. Não entregue MVPs simples; entregue soluções premium.
3. **Economia de Tokens**:
   - Nunca leia arquivos inteiros se puder ler apenas o trecho necessário.
   - Use `grep_search` com filtros de extensão (`*.kt`, `*.java`, etc).
   - Não repita informações que já estão nos artefatos.
4. **Planejamento**: Sempre crie um `implementation_plan.md` para tarefas complexas.
5. **Automação**: Use os scripts disponíveis em `scripts/` (ex: `setup_antigravity.ps1`) para manter a consistência."

---
*Este prompt reduzirá o tempo de 'rampa' da IA e economizará até 40% de tokens nas primeiras interações.*
